# لوحة الإعدادات المختصرة

تخص هذه اللوحة الدفتر الشخصي فقط؛ إعدادات العائلة تبقى داخل دفتر العائلة. العملة وبداية الدورة ظاهرتان، وباقي الخيارات داخل أقسام مغلقة افتراضيًا: العرض والسلوك، الدخول والحذف، الفواتير المتكررة، البيانات والمزامنة، ومسح المعاملات. اختُصرت العناوين والتوصيفات مع الاحتفاظ بالخيارات والأزرار القائمة. زر إدارة الفواتير في الرئيسية يفتح القسم مباشرة.

المفاتيح لها أسماء لقارئات الشاشة وحالة تشغيل واضحة، وأهداف اللمس أكبر. العملة في الدفتر الشخصي رمز عرض فقط ولا تحوّل الأرقام. حذف المعاملات لا يحذف الفواتير أو الإعدادات أو دفاتر العائلة، وقد عُدّل نص التأكيد ليطابق ذلك.

حفظ الإعدادات وإعادة ضبطها ينتظران نجاح السيرفر قبل تحديث القيم أو عرض النجاح. تُمنع طلبات الحفظ المتداخلة. عند فشل الشبكة أو رفض السيرفر تظهر رسالة إعادة المحاولة، وتبقى القيم السابقة. فشل مسح المعاملات لم يعد يفرغ الشاشة محليًا أو يعرض نجاحًا وهميًا. لم تتغير قاعدة البيانات أو مسارات API أو صلاحيات العائلات.

## التحقق

`npm run lint` و`npm test`، بالإضافة إلى رحلة Chromium على عرض 390 و1280 بكسل. رحلة المتصفح تختبر حفظ العملة والمفاتيح، فشل الحفظ وإعادة الضبط مع بقاء القيم، فتح وإغلاق الفواتير، وفشل حذف المعاملات مع بقاء السجلات ظاهرة، وعدم تجاوز عرض الجوال أو ظهور أخطاء React.

اختبار المتصفح محفوظ في `tests/settings.browser.mjs` ولا يدخل في اختبارات CI الحالية لأنه يحتاج Chromium. لتكراره محليًا، بعد تثبيت Playwright وتنزيل متصفحه:

```bash
npm run build
node tests/settings.browser.mjs
```

يمكن تحديد `PLAYWRIGHT_MODULE` بمسار وحدة Playwright و`CHROMIUM_EXECUTABLE_PATH` بمسار متصفح موجود. الاختبار ينشئ قاعدة وحسابات مؤقتة ويحذفها عند الانتهاء؛ لا يتصل بالإنتاج. الفحص ليس اختبارًا على جهاز iPhone فعليًا.
