# إدخال المصروف من رسالة البنك

من شاشة المصروف أو المعاملة المشتركة، افتح «لصق رسالة البنك» والصق رسالة شراء واحدة. المبلغ بالإنجليزية واسم المتجر والتاريخ يملؤون تلقائيًا؛ اختر التصنيف وراجع ثم اضغط حفظ. الفاصل العشري والأرقام العربية والفارسية مدعومة.

تدعم الرسائل الأربع المقدمة: POS، Amazon، OPENAI، Jeeny بصيغ SAR وSR. يُستخرج مبلغ الشراء المسمى «بـ» أو «مبلغ»، ويُتجاهل الرصيد المتبقي والمبلغ المكرر بين الأقواس وأرقام الحساب والبطاقة. التاريخ يُقرأ يوم/شهر/سنة؛ التاريخ غير الصحيح لا يغيّر التاريخ المختار. الرسالة متعددة العمليات أو غير المفهومة أو المرتجعة لا تُطبق وتترك الحقول كما هي. لا يحدث تحويل عملات.

المعالجة محلية ولا تحتاج خدمة ذكاء اصطناعي أو اتصالًا بالإنترنت. نص الرسالة لا يُرسل ولا يُخزّن في التطبيق؛ يُفرغ من الخانة بعد الاستخراج. يُحفظ فقط المصروف المعتاد عند التأكيد: مبلغ، تصنيف، تاريخ، واسم المتجر كالوصف. لا توجد تغييرات في قاعدة البيانات أو الصلاحيات أو البيانات الحالية.

اختبارات التحليل تشمل الرسائل الأربع، أرقامًا عربية وفواصل آلاف، الغموض والمرتجعات والعملات غير المدعومة والتواريخ غير الصحيحة. اختبار المتصفح الاختياري يغطي لصق رسالة OPENAI وحفظ مبلغ الشراء بدل الرصيد مع غياب رقم البطاقة عن المعاملة.
